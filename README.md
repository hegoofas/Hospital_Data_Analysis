# 🏥 Hospital Analytics Dashboard – SQL, Python, Power BI

This project showcases an end-to-end analytics workflow built using SQL, Python, and Power BI, transforming hospital operational data into clear, actionable insights.

## 📌 Project Overview
A fully integrated dashboard analyzing hospital performance across patients, staff, finance, diagnoses, and care services.  
The system is built on a fictional hospital database consisting of 12 interconnected tables, processed and cleaned using Python, and finally visualized in Power BI.

## 📂 Dataset Structure
The database contains 12 relational tables:
- Admissions  
- Patients  
- Cities  
- Department  
- Staff  
- Medications  
- Procedures  
- Procedures_Lookup  
- Lab_Results  
- Billing  
- Diagnoses  
- Drugs

This structure enabled comprehensive analysis across patient care, billing, staffing, and medical activities.

## 🔍 What I Worked On
### 1️⃣ SQL – Data Integration & Modeling
- Joined all 12 tables into one `fact_table` for analysis  
- Created correct relationships across all dimensions  
- Ensured data integrity for downstream analytics  

### 2️⃣ Python – Data Cleaning & Quality Checks
Using Pandas & NumPy, I performed:  
- Handling missing values  
- Correcting data types  
- Outlier detection & treatment  
- Duplicate removal  
- Ensuring consistency across all tables  

### 3️⃣ Power BI – Data Modeling & Visualization
- Applied Power Query transformations  
- Built advanced DAX measures (KPIs, YoY%, growth metrics)  
- Created calculated columns for deeper segmentation  
- Designed a full Date Table for time intelligence  
- Built dynamic, interactive reports using slicers & navigation buttons  

### 4️⃣ PowerPoint – Design
- Designed all dashboard backgrounds from scratch  
- Applied a clean, professional theme across all pages  

## 📊 Dashboard Reports
The dashboard includes 5 main reports:

1️⃣ **Overview Report**  
- Admissions  
- Patient counts  
- Readmission rates  
- Insurance coverage  
- YoY growth  

2️⃣ **Patients Report**  
- Patient flow  
- Readmission analysis  
- Demographic insights  

3️⃣ **Staff Report**  
- Staff distribution  
- Workload analysis  
- Doctors vs. nurses performance  

4️⃣ **Finance Report**  
- Charges vs. payments  
- Insurance vs. non-insurance revenue  
- Billing trends  

5️⃣ **Care Report**  
- Diagnoses  
- Medication usage  
- Procedures analysis  

Each report includes slicers and navigation controls for a seamless experience.
